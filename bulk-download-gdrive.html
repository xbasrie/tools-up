Bulk Download GDrive

Download dan kelompokkan file Google Drive dari link di Google Sheet

info
Petunjuk Penggunaan:
  • Pastikan Google Sheet Anda memiliki akses "Anyone with the link" (Siapa saja yang memiliki link).
  • Pastikan file-file di dalam Google Drive juga memiliki akses "Anyone with the link".
  • Sistem akan mendownload semua file dari Google Drive Anda dan mengelompokkannya ke dalam folder di dalam satu file ZIP.

folder Penamaan Folder

Pilih kolom yang akan digabungkan menjadi nama folder. (Misal: Pilih kolom "NIP" & "Nama")

link Kolom Link GDrive

Pilih kolom mana saja yang berisi link file Google Drive untuk didownload.
